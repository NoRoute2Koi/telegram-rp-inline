## Телеграм бот для РП действий в ЛС
### Проект полностью вайбкод, я не скрываю этого !!!
### Описание
С помощью данного бота вы сможете вызывать РП действия в личке с собеседником инлайн. аналог iriscm но только для действий
### Использование (инлайн)
`@bot погладить` - отправить собеседнику запрос на действие. он может либо принять, либо отказаться
### Использование (личка с ботом)
`/help` - доступные действия
`/setname имя` - установить своё имя вместо firstname (сохраняется в bot.db)
### Первый запуск
1. клонирование репозитория и установка зависимостей
  ```
  git clone https://github.com/noroute2koi/telegram-rp-inline
  cd telegram-rp-online
  python -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  ```
2. редактирование конфига
  ```
  BOT_TOKEN = "adc:123"              # токен бота из @botfather
  BOT_USERNAME = "your_bot_username" # юзернейм вашего бота (отображается в /start и /help)

  [actions]                          # доступные действия
  example = ["ГЛАГ-1", "ГЛАГ-2"]     # ГЛАГ-1 -- действие в инфинитиве, используется для вызова в инлайне
  hug = ["обнять", "обнял(а)"]       # ГЛАГ-2 -- действие в прошедшем времени, используется для сообщения после принятия действия собеседником
  pat = ["погладить", "погладил(а)"] # Пока что род не поддерживается, используется "(а)" в конце ГЛАГ-2 для лучшего отображения
  ```
3. запуск бота
  `python bot.py`
