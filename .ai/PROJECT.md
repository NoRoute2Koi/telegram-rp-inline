### PROJECT.md

## Идея
Данный проект это inline бот для telegram для РП-действия. Допустим человек может вызвать действие "обнять", чтобы виртуально обнять собеседника.

## работа
- при запуске бота (т.е /start) он выдаёт сообщение "test"
- при использовании inline в ЛС бот выводит инлайн кнопки
  - при пустом inline запросе от пользователя бот показывает карточку "пожалуйста, укажите действие"
  - при указании действия бот выводит карточку для отправки запроса(обычное сообщение) собеседнику для выполнения действия
- в инлайн вводе действие пишется в инфинитиве. в сообщении, если собеседник согласился на действи, то в прошедшем времени

## пояснения
- собеседник это тот, кто нажал кнопку в сообщении
- карточки это Telegram Inline Query Results — элементы, которые бот возвращает при вводе @bot query в поле сообщения. В моём случае это не картинки, а текстовые варианты/пункты, на которые пользователь может нажать. Они отображаются над клавиатурой как список результатов inline-запроса.
- возвращать одну карточку

## код, структура проекта, логика
- весь код лежит в bot.py
- используй библеотеку python-telegram-bot последней версии
- в корне проекта лежит config-reference.toml. в нём содержатся bot_token, поддерживаемые действия (т.е. обнять или подобное)
- действие должно писаться в двух вариантах: инфинитив и прошедшее время, род не учитывается тк используется формат "обнял(а)"
- используется firt name для имени в сообщениях
- состояние хранить временно
- при неизвестном действии вывести карточку с ошибкой
- сам скрипт использует конфиг из config.toml
- имя того кто принеял определяется через кнопку "принять" в сообщении 

## Примеры

**поле ввода:** `@bot обнять`
**карточка:** `предложить обнять собеседника` (карточка это сама по себе кнопка в инлайне)
**сообщение после отправки действия:**
```
  [имя того, кто использовал инлайн/отправил соо] хочет обнять
  [кнопка принять] [кнопка отказ]
```
**сообщение после принятия:**
```
  [имя того кто вызвал] обнял [имя того кто принял]
```

**сообщение после отказа:**
```
  предложение обнять было отвергнуто
```
